# 프로젝트 전체 목적

## 프로젝트 개요

**IPEDS-downloader**는 IPEDS(Integrated Postsecondary Education Data System) 데이터를 웹에서 다운로드하고, 가공하여 시계열 분석이 가능한 통합 데이터베이스를 구축하는 프로젝트입니다.

## 주요 목표

### 1. 데이터 수집
- **IPEDS 웹사이트에서 데이터 자동 다운로드**
- 다양한 연도와 학기의 데이터를 체계적으로 수집
- 안정적이고 효율적인 다운로드 프로세스 구현

### 2. 데이터 변환 및 정규화
- **컬럼명을 자연어로 변환**
  - 기계가 읽는 코드형 컬럼명을 사람이 이해할 수 있는 자연어로 변환
  - 예: `UNITID` → `기관 식별 코드`, `INSTNM` → `기관명`

- **코드값을 자연어로 변환**
  - 숫자 코드로 표현된 범주형 데이터를 의미있는 텍스트로 변환
  - 예: `1` → `공립`, `2` → `사립`, `3` → `영리`
  - **단, 실제 수치 데이터는 그대로 유지** (학생 수, 금액 등)

### 3. 시계열 데이터 구조화
- **연도별, 학기별 데이터 분리**
  - 각 데이터를 연도(year)와 학기(term) 기준으로 구분
  - 시간 차원을 명확하게 식별할 수 있도록 구조화

- **시간별 적재 가능한 데이터베이스 설계**
  - 동일한 기관의 시계열 변화 추적 가능
  - 연도별, 학기별 비교 분석 용이
  - 장기 트렌드 분석 지원

### 4. 통합 데이터베이스 구축
- **단일 통합 데이터베이스 생성**
  - 여러 연도, 학기의 데이터를 하나의 데이터베이스에 통합
  - 일관된 스키마와 데이터 형식 유지
  - 효율적인 쿼리 및 분석 지원

## 데이터 처리 파이프라인

```
1. 웹 수집
   ↓
   [IPEDS 웹사이트에서 원본 데이터 다운로드]

2. 데이터 파싱
   ↓
   [CSV/Excel 파일 읽기 및 구조 분석]

3. 메타데이터 매핑
   ↓
   [컬럼명 및 코드값 사전 참조]

4. 자연어 변환
   ↓
   [컬럼명 → 자연어]
   [코드값 → 자연어 (숫자 데이터는 유지)]

5. 시간 차원 추가
   ↓
   [연도, 학기 정보 추가 및 구조화]

6. 데이터베이스 적재
   ↓
   [통합 데이터베이스에 저장]

7. 검증 및 품질 관리
   ↓
   [데이터 무결성 확인]
```

## 핵심 기능 요구사항

### 데이터 다운로드
- 자동화된 데이터 수집 스크립트
- 중단/재시도 기능
- 진행상황 모니터링

### 데이터 변환
- 컬럼명 매핑 사전 관리
- 코드-자연어 변환 사전 관리
- 숫자/텍스트 데이터 구분 로직

### 데이터베이스 관리
- 시계열 데이터 스키마 설계
- 효율적인 인덱싱
- 데이터 버전 관리

### 품질 관리
- 데이터 무결성 검증
- 중복 데이터 처리
- 에러 로깅 및 추적

## 예상 사용 사례

### 교육 정책 분석
- 특정 대학의 연도별 학생 수 변화 추적
- 지역별 고등교육 기관 트렌드 분석
- 등록금 변화 패턴 연구

### 기관 비교 분석
- 동일 유형 기관들의 특성 비교
- 전국 평균 대비 개별 기관 위치 파악
- 시계열 성과 지표 비교

### 연구 및 보고서
- 고등교육 통계 리포트 생성
- 학술 연구를 위한 데이터 제공
- 정책 의사결정 지원 자료

## 기술 스택 (예상)

### 데이터 수집
- Python requests/selenium (웹 스크래핑)
- pandas (데이터 처리)

### 데이터 저장
- SQLite/PostgreSQL (관계형 데이터베이스)
- 또는 Parquet/HDF5 (컬럼 기반 저장)

### 데이터 처리
- pandas/polars (데이터 변환)
- 정규 표현식 (텍스트 처리)

## 성공 지표

1. ✅ 모든 필요한 연도/학기 데이터 수집 완료
2. ✅ 95% 이상의 컬럼명이 자연어로 변환
3. ✅ 95% 이상의 코드값이 자연어로 변환
4. ✅ 시계열 분석 가능한 통합 데이터베이스 구축
5. ✅ 데이터 무결성 100% 유지

## 주의사항

### 데이터 변환 시
- **숫자 데이터는 변환하지 않음**: 학생 수, 금액, 비율 등 실제 수치는 원본 유지
- **코드값만 변환**: 범주형 변수의 코드 (1, 2, 3 등)만 자연어로 변환
- **일관성 유지**: 동일한 코드는 항상 동일한 자연어로 변환

### 시계열 데이터 관리
- **시간 순서 보장**: 연도와 학기 정보를 명확히 저장
- **중복 방지**: 동일 기관-시점 데이터의 중복 적재 방지
- **버전 관리**: 데이터 업데이트 이력 추적
